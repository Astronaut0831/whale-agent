# 人脑记忆机制 vs 哦鲸鲸记忆框架

> 讨论稿。目的：用认知神经科学的成熟机制对照现有实现，找出“像”和“缺”。

## 2. 现有框架分层

| 层 | 实现 | 近似脑机制 |
|---|---|---|
| L0 消息 | `store`，保留 500 条 | 情景缓冲/海马快存 |
| L1 摘要 | `digest` → 叙事线 | 离线巩固、图式化 |
| L2 事实 | `memories.json`，向量+关键词召回 | 语义记忆（新皮层） |
| L3 规矩 | `prefs` | 图式/规则 |
| L4 自我 | `selfnote`、人设 | 自我图式 |
| 工作记忆 | 上下文窗口 120/150 条 | 工作记忆容量 |
| 遗忘 | 墓碑、superseded、裁剪 | 抑制/消退 |
| 来源 | `origin`、`privacy`、`recall_self` | 源监控（部分） |

## 3. 逐项对照

### 3.1 工作记忆与情景缓冲

- 脑：容量有限（约 4 个组块），靠复述/刷新维持；情景缓冲整合多模态。
- 现在：上下文窗口 + 气泡 + 摘要注入；没有“复述/刷新”，只有按条数截断。
- 差距：缺少**容量感知的分块**（把长对话压成组块再进窗口），以及“刚说过的话”优先级保护。

### 3.2 情景 vs 语义

- 脑：情景记忆带时间、地点、来源；语义记忆是去情境化的事实。
- 现在：L0 情景、L2 事实分离正确；但**事实不带原始出处/时间**，只剩一句摘要。
- 差距：事实应保留 `quote`、`msgId`、`ts`、`confidence`，否则无法源监控、无法纠错。

### 3.3 编码：情感与自我参照

- 脑：情绪唤醒（杏仁核）增强编码；自我参照效应让“关于我”的信息记得更好。
- 现在：`importance` 默认 0.5，没有情绪强度、没有自我参照加权。
- 差距：你刚发的情绪语料，在脑里会被优先巩固；现在和普通事实同权。

### 3.4 巩固（海马→皮层）

- 脑：离线重放 + 睡眠依赖巩固，优先重放高显著/情绪事件；先 gist 后细节。
- 现在：`digest` 在 idle 30min / 4000 token 时做摘要；不分显著度。
- 差距：没有**显著性加权的重放**；没有夜间深度整理（合并、去噪、重算向量）。

### 3.5 再巩固

- 脑：记忆被提取后进入不稳定窗口，可被更新/削弱。
- 现在：检索只 `markUsed`（加一点 recency）；只有“同主体不同数字”才 automatic supersede。
- 差距：用户纠正时，旧事实不会进入“可改写”状态；缺少**提取后更新**。

### 3.6 提取与情境依存

- 脑：编码特异性；线索匹配；提取练习会强化记忆。
- 现在：`sameCtx +0.08`、关键词+向量混合；没有提取练习。
- 差距：召回不会让记忆更牢（除了 recency），也没有间隔复现。

### 3.7 遗忘与干扰

- 脑：遗忘是适应性的（按检索概率/价值），既有衰减也有**干扰抑制**；提取一个会抑制竞争者。
- 现在：30 天指数衰减、墓碑、裁剪；没有干扰抑制。
- 差距：相近事实会一起被召回（“李益凯/主人”4 条重复），正是缺**竞争抑制/去重**。

### 3.8 源监控与虚假记忆

- 脑：来源监控失败→把想象当经历；建构性记忆会“合理编造”。
- 现在：`origin` 做隔离，`recall_self` 做自查；但模型仍会“翻回去看”式自信否认。
- 差距：需要**置信度标定**和“来源不可用就说不确定”的硬规则（已部分修）。

## 4. 改进优先级

1. **事实带出处**：`quote/msgId/ts/confidence`，可核对。
2. **显著性加权**：情绪强度、自我相关、用户纠正 → importance。
3. **干扰抑制/去重**：召回时对近似事实做竞争抑制（RIF 启发）。
4. **再巩固**：用户纠正时把旧事实标 superseded，并把新说法写回。
5. **离线巩固**：夜间合并/去重/剪枝/重算向量；显著事件优先重放。
6. **提取练习**：重要事实按间隔复现（谨慎，避免打扰）。
7. **容量分块**：长对话先摘要成组块再进上下文。

## 5. 一句话总结

结构上已经是“海马 + 皮层”的工程近似；差的是**显著性、再巩固、干扰抑制、源监控**这四个“生物细节”，而它们恰好决定“她记不记得住、会不会串、错了能不能改”。

| ③ 干扰抑制/去重 | 召回时近义竞争抑制 + `recallPenalty`（RIF 启发）；巩固时机械只合并 ≥0.9 的近同，0.3–0.9 交给模型判断 | `近义事实召回时互相抑制` |

## 7. 粒度与检索优化（2026-11-02 晚）

- 摘要要求**一条只讲一件事**，模型仍复合时分号强制拆条；
- 每条带 `about`（user/her/relation/other），缺失时按内容兜底推断；
- 模型输出源消息序号 `msg`，出处精确到**那一条消息**；缺失时按文本相似度回找；
- 模型判重时要求输出 `merged` 合并文本，保留双方关键信息；
- 召回权重改为 `0.6*相关 + 0.2*重要性 + 0.2*时近`，降低旧高重要性事实的压制；
- 同义扩展（竞赛→省一/省队，焦虑→压力/失眠…），原句与扩展句取高分，避免稀释；
- QA 评测：12 条真实语料问题，hit@3 **12/12**；
- 测试语料已清理：合成消息、`小八` 测试事实、临时评测目录均不保留。
- **拆条交给模型**（`src/factSplit.js`）：只有疑似复合句（分号，或 ≥28 字且 2 个以上逗号）才触发；
  模型输出原子事实，最多拆 4 条，保留 `about/msg`；空返回/失败时退回分号规则；配置 `memory.splitWithModel=false` 可关闭。
- **原句级出处**（`src/quoteSpan.js`）：在消息内按句子/分句匹配，存 `quoteSpan{start,end}`，quote 只保留最相关那一句。
- **自动再巩固**（`src/reconsolidate.js`）：主人私聊出现“不对/其实是/记错”时，模型判断旧事实与新事实，自动推翻旧值并写入。
- **间隔提取练习**：召回后按 1/3/7/30 天排复习；到期的重要事实作为“可自然想起”提示注入私聊。
- **睡眠期显著性重放**：夜间巩固挑高重要性事实重放，小幅强化并记录 `replayCount`。
- **情景记忆**：事实带 `episode{session,chatType,at}`，`timeline()` 可按时间回看；召回带日期/来源。
- **适应性遗忘**：按 `0.6*重要性 + 0.3*使用度 + 0.1*时近` 估值，低于阈值且超过 60 天的旧事实淘汰。
- **合并保真**：模型合并文本缺少原句数值时，自动追加原句，避免“省一37名”被概括吞掉。
