## P4 must-have 剩余

1. 真实非主人私聊回归；
2. 群主动话题真实触发（已 armed，需 2 小时静默窗口）；
3. `/dl` 真实微信命令复核（本地网络下载路径已通过）；
4. 统一故障手册与安全边界（部分已有）。

## 安全边界

- 普通 `whale-headless` 继续禁用 `tool-fs` / `tool-fs-search` / `tool-working-directory`；
- 后台任务专用 `whale-headless-task` 才开启 workspace 文件工具；
- `/run` 仅主人、必须 `--yes`、限 workspace、15 秒；
- `/dl` 仅主人、http/https、20MB；
- `/api/gui/input` 仅 loopback、`guiInput` 开关、支持 `sessionId`；
- 默认 web profile 不装 `whale-fixed-session` / `whale-gui-input`；
- 所有 profile 改动有 `.bak-*` 备份。
